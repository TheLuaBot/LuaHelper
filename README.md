
# Lua Helper

Bot do Discord com comandos de ban/unban e funções administrativas.

## Self Hosting

Este bot pode ser auto-hospedado. Para isso:

1. Clone o repositório:
```bash
git clone https://github.com/SeuUsuario/LuaHelper.git
````

2. Instale as dependências:

```bash
pip install -r requirements.txt
```

3. Crie um arquivo `.env` com seu token:

```
TOKEN=SEU_TOKEN_AQUI
```

4. Execute o bot:

```bash
python main.py
```

Agora ele vai rodar no seu computador ou servidor.
